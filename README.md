# Desk panel

One full-page tile for a desk. With the monitor off it shows large keys that start a source; with the monitor on, the
sources with a dot for each device that runs, the monitor's keys, an Auto key and a key for a device such as a PC.

## Set up

1. In Tessera, open **Plugins**, choose **Add with a link** and paste `https://github.com/Orishas/tessera-desk-panel`.
2. Add the plugin to a screen. The screen builds once.
3. In **Layout**, place the **Desk panel** tile from the library's Plugins group over a whole page.
